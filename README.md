# Project Showcase

A personal portfolio and project showcase built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

The purpose of this website is to document projects, architectural decisions, implementation details, lessons learned, and experiments related to modern web development and AI-powered applications.

Rather than functioning as a traditional blog, the site serves as a collection of technical case studies intended to complement my résumé and GitHub profile.

## Features

- Project case studies
- Technology summaries
- Architecture notes
- Screenshots and demonstrations
- Live project links
- Repository links
- Responsive design

## Technology stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- MDX
- Vercel

## Running locally

```bash
npm install
npm run dev
```
